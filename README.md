# NexDesk
### Manage Every Workspace. From One Dashboard.

NexDesk is a Multi-Center Coworking CRM + ERP platform designed to help coworking operators manage operations from a single dashboard.

## Problem

Coworking operators often use multiple disconnected tools for:
- Lead management
- Bookings
- Seat allocation
- Renewals
- Billing

This creates inefficiencies and reduces operational visibility.

---

## Solution

NexDesk centralizes coworking operations into one platform.

Users can:
- Manage leads
- Track bookings
- Monitor seat availability
- Handle renewals
- Manage billing
- View business insights

---

## Features

- Dashboard Analytics
- Leads CRM
- Booking Management

- Renewals Tracking
- Finance & Billing
